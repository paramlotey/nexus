# NEXUS

A Mini SaaS collaboration platform inspired by Notion, Trello, and Slack.

## Status

🚧 Under Development

## Planned Stack

### Frontend

- React
- Vite
- Redux Toolkit
- React Hook Form

### Backend

- Node.js
- Express.js
- MongoDB
- Redis
- BullMQ
- Socket.io

### DevOps

- Docker
- Docker Compose
- GitHub Actions
- Swagger/OpenAPI

## Core Features

- JWT authentication
- Refresh tokens
- Role-based access control
- Workspace management
- Project and task management
- Kanban boards
- Documents
- Team chat
- Real-time notifications
- File uploads
- Search
- Audit logs
- Background jobs
- Offline support
